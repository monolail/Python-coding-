## 🔢 풀이 완료 문제 목록

### ✅ 이분탐색 (Binary Search)

#### 1. 이분 검색
- **접근**: 버블 정렬로 배열 정렬 후 이분탐색으로 M의 위치 탐색
- **핵심**: `first`, `end` 포인터로 범위를 절반씩 줄여나가기
- **시간복잡도**: O(N log N) — 정렬 O(N²) + 탐색 O(log N)
```python
def Binary_search(arr):
    first, end = 0, N-1
    while first <= end:
        mid = (first + end) // 2
        if arr[mid] == M: return mid
        elif arr[mid] > M: end = mid - 1
        else: first = mid + 1
    return -1
```

---

#### 2. 랜선 자르기
- **접근**: 이분탐색으로 "M개 이상 만들 수 있는 최대 길이" 탐색
- **핵심**: `Count(mid)` 함수로 해당 길이로 잘랐을 때 개수 계산
- **패턴**: 파라메트릭 서치 (Parametric Search) — 조건을 만족하는 최적값 탐색
```python
while lt <= rt:
    mid = (lt + rt) // 2
    if Count(mid) >= M:
        res = mid       # 가능하면 기록하고 더 크게 시도
        lt = mid + 1
    else:
        rt = mid - 1    # 불가능하면 더 작게 시도
```

---

#### 3. 뮤직 비디오
- **접근**: DVD 용량을 이분탐색으로 결정 (M개 DVD에 담을 수 있는 최소 용량)
- **핵심**: `Count(capacity)` 함수로 해당 용량으로 몇 개 DVD가 필요한지 계산
- **패턴**: 랜선 자르기와 동일한 파라메트릭 서치 패턴 (방향 반대)
```python
while lt <= rt:
    mid = (lt + rt) // 2
    if mid >= largest and Count(mid) <= M:
        rt = mid - 1
        res = mid       # 가능하면 기록하고 더 작게 시도
    else:
        lt = mid + 1
```

#### 4. 마구간 정하기
- **접근**: 말 사이 최소 거리를 이분탐색으로 결정 (C마리 배치 가능한 최대 거리)
- **핵심**: 정렬 후 `Count(len)` 함수로 해당 거리 간격 이상일 때 배치 가능한 말 수 계산
```python
Line.sort()
while lt <= rt:
    mid = (lt + rt) // 2
    if Count(mid) >= C:
        res = mid
        lt = mid + 1
    else:
        rt = mid - 1
```

### ✅ 그리디 (Greedy)

#### 5. 회의실 배정
- **접근**: 끝나는 시간 기준으로 정렬 후 겹치지 않는 회의 최대 개수 선택
- **핵심**: `lambda x: (x[1], x[0])` — 끝 시간 우선, 동률이면 시작 시간 순 정렬
- **그리디 근거**: 빨리 끝나는 회의를 선택할수록 다음 회의를 더 많이 넣을 수 있음
```python
meeting.sort(key=lambda x: (x[1], x[0]))
for s, e in meeting:
    if s >= et:
        cnt += 1
        et = e
```

---

#### 6. 씨름 선수
- **접근**: 키 내림차순 정렬 후 몸무게 최댓값을 추적하며 합격자 카운트
- **핵심**: 키가 더 큰 사람은 이미 처리됐으므로 몸무게만 비교하면 됨
- **그리디 근거**: 한 기준으로 정렬하면 다른 기준만 비교하는 1차원 문제로 환원
```python
Profile.sort(reverse=True)  # 키 기준 내림차순
Heavy = 0
for x, y in Profile:
    if y >= Heavy:
        cnt += 1
        Heavy = y
```

---

#### 7. 창고 정리
- **접근**: 정렬 후 M번 반복하여 최솟값 +1, 최댓값 -1을 수행
- **핵심**: 매 연산 후 재정렬하여 항상 최솟값과 최댓값을 정확히 파악
```python
storage.sort()
for i in range(M):
    storage[0] += 1
    storage[L-1] -= 1
    storage.sort()
print(storage[L-1] - storage[0])
```

## 💡 핵심 개념 정리

| 개념 | 설명 | 시간복잡도 |
|------|------|-----------|
| **이분탐색** | 정렬된 배열에서 mid를 기준으로 탐색 범위를 절반씩 축소 | O(log N) |
| **파라메트릭 서치** | "최적값"을 이분탐색으로 결정하는 패턴 (랜선, 뮤직비디오, 마구간) | O(N log N) |
| **버블 정렬** | 인접 원소를 반복 비교·교환 | O(N²) |
| **그리디** | 현재 단계에서 최선의 선택을 반복해 전체 최적해 도달 | 문제마다 다름 |
| **정렬 기준 설정** | `sort(key=lambda x: ...)` 로 다중 기준 정렬 | O(N log N) |
