## 🔢 풀이 완료 문제 목록

### ✅ 재귀함수와 DFS 기초

#### 1. 재귀함수를 이용한 2진수 출력
- **핵심**: 스택 프레임의 원리를 활용하여 재귀 호출 이후에 `print`를 작성해 역순 출력 유도

#### 2. 이진트리 순회 (깊이우선탐색 연습)
- **핵심**: 부모 노드 `v`에서 왼쪽 자식은 `v*2`, 오른쪽 자식은 `v*2+1`로 호출하여 전/중/후위 순회 시뮬레이션

#### 3. 부분집합 구하기 (DFS)
- **핵심**: 상태트리를 구성하여 `ch` 배열에 원소 포함 여부(0 또는 1)를 기록하며 탐색

#### 4. 합이 같은 부분집합
- **핵심**: 부분집합 합계가 전체 합계의 절반과 같은지 확인 (`sys.exit(0)`으로 조기 종료)

#### 5. 바둑이 승차
- **핵심**: 합계가 제한을 초과하면 조기 종료(Cut Edge), 남은 원소의 총합을 더해도 현재 최댓값을 넘지 못하면 조기 종료하여 최적화

#### 6. 중복순열 구하기
- **핵심**: 체크 배열 없이 `a` 배열에 값을 덮어쓰며 여러 번 선택 가능한 순열 구성

#### 7. 동전 교환
- **핵심**: 동전을 내림차순 정렬하여 가장 큰 금액부터 차감하도록 DFS 호출, 현재 기록된 최소 동전 수보다 깊어지면 조기 종료(Cut Edge)

#### 8. 순열 구하기
- **핵심**: `ch` 체크 배열을 두어 이미 사용한 원소인지 판별하며 DFS 트리 탐색 후, 돌아올 때 다시 `ch[i] = 0`으로 복구

#### 9. 수열 추측하기
- **핵심**: 파스칼의 삼각형 원리(이항계수)를 응용해 맨 윗줄의 조합별 가중치 배열 `b`를 만들고 순열마다 곱을 더하여 일치 여부 확인

#### 10. 조합 구하기
- **핵심**: 순열과 달리 시작점 `start` 파라미터를 넘겨주어 자신보다 큰 원소들만 탐색하게 유도

#### 11. 수들의 조합
- **핵심**: 입력받은 리스트에서 조합을 추출하여 합계가 특정 배수인지 판별

#### 12. 인접 행렬 (그래프 기초)
- **핵심**: 노드 개수 `N`에 맞춰 2차원 리스트를 생성하고 간선(Edge)과 가중치를 표현

#### 13. 경로 탐색 (그래프 DFS)
- **핵심**: 방문한 노드는 `ch[i] = 1`로 체크하고 DFS를 타고 들어가며, 백트래킹 시 `ch[i] = 0`으로 되돌려 다른 경로를 허용

## 💡 핵심 개념 정리

| 개념 | 설명 | 활용 패턴 |
|------|------|-----------|
| **재귀함수 (Recursion)** | 함수 내부에서 자기 자신을 다시 호출하는 함수 | 종료 조건(Base Case)이 필수, 스택(Stack) 메모리 사용 |
| **스택 프레임 (Stack Frame)** | 함수 호출 시 메모리에 쌓이는 구조 | 재귀 호출 코드 아래의 명령어는 가장 깊은 호출부터 역순 실행 |
| **깊이우선탐색 (DFS)** | 트리의 바닥(단말 노드)까지 먼저 파고드는 탐색 | 상태트리 탐색, 모든 경우의 수 완전탐색 |
| **백트래킹 & Cut Edge** | 조건에 안 맞으면 탐색 중단(Return) | 유망하지 않은 가지는 조기에 쳐내어(Pruning) 실행 속도 단축 |
| **순열 vs 조합** | 상태트리 구성의 차이점 | 순열은 `ch` 배열 활용, 조합은 `start` 인덱스 파라미터 활용 |
