## 🔢 풀이 완료 문제 목록

### ✅ 재귀함수와 DFS 기초

#### 1. 재귀함수를 이용한 2진수 출력
- **접근**: 숫자를 2로 나눈 몫을 재귀적으로 넘기고, 나머지를 출력
- **핵심**: 스택 프레임의 원리를 활용하여 가장 마지막에 호출된 함수(가장 작은 몫)부터 역순으로 나머지가 출력되도록 함 (재귀 호출 이후에 `print` 작성)

#### 2. 이진트리 순회 (깊이우선탐색 연습)
- **접근**: 완전이진트리를 배열이 아닌 재귀함수로 탐색 시뮬레이션
- **핵심**: 부모 노드 `v`에서 왼쪽 자식은 `v*2`, 오른쪽 자식은 `v*2+1`로 호출
  - **전위 순회(Pre-order)**: 부모 -> 왼쪽 -> 오른쪽 (호출 전에 본인 처리)
  - **중위 순회(In-order)**: 왼쪽 -> 부모 -> 오른쪽 (왼쪽 자식 호출 후 본인 처리)
  - **후위 순회(Post-order)**: 왼쪽 -> 오른쪽 -> 부모 (양쪽 자식 호출 후 본인 처리)

#### 3. 부분집합 구하기 (DFS)
- **진행 중**: 상태트리 구성 연습

## 💡 핵심 개념 정리

| 개념 | 설명 | 활용 패턴 |
|------|------|-----------|
| **재귀함수 (Recursion)** | 함수 내부에서 자기 자신을 다시 호출하는 함수 | 종료 조건(Base Case)이 필수, 스택(Stack) 메모리를 사용 |
| **스택 프레임 (Stack Frame)** | 함수 호출 시 메모리에 쌓이는 구조 | 재귀 호출 코드 아래에 있는 명령어는 가장 깊은 호출부터 역순으로 실행됨 |
| **깊이우선탐색 (DFS)** | 트리의 바닥(단말 노드)까지 먼저 파고드는 탐색 | 상태트리 탐색, 모든 경우의 수 탐색(완전탐색), 백트래킹 |
| **상태트리** | 문제의 모든 상태(선택)를 트리 형태로 나타낸 것 | 포함한다(O) / 안 한다(X)의 두 가지 분기로 트리를 뻗어나감 |
