## 🔢 문제 목록 및 풀이 요약

### 1. 회문 문자열 검사
- **접근**: 입력 문자열을 소문자로 변환 후 뒤집어서 비교
- **핵심**: `a.lower()` + `a[::-1] == a`
```python
a = a.lower()
if a[::-1] == a:
    result.append(1)
```

---

### 2. 숫자만 추출
- **접근**: 문자열을 순회하며 숫자만 골라낸 뒤 약수 개수 계산
- **핵심 (ver1)**: `i.isnumeric()`으로 숫자 판별
- **핵심 (ver2)**: ASCII 코드 활용 (`ord(i) >= 48 and ord(i) <= 57`)

---

### 3. 카드 역배치 (정올 기출)
- **접근**: 주어진 구간 [s, e]를 10번 반복하여 제자리 스왑
- **핵심**: 인덱스 기반 스왑으로 슬라이싱 없이 뒤집기
```python
for i in range((e - s + 1) // 2):
    a[e-i], a[s+i] = a[s+i], a[e-i]
```

---

### 4. 두 리스트 합치기
- **접근**: 두 리스트를 합친 뒤 정렬하여 출력
- **핵심**: `+` 연산자로 리스트 병합 or `append()` 반복

---

### 5. 수들의 합
- **접근**: 투 포인터(Two Pointer)로 연속 부분합이 M인 경우 카운트
- **핵심**: O(N) 시간복잡도로 해결 (브루트포스 O(N²) 대비 효율적)
```python
while True:
    if tot < M:
        tot += a[rt]; rt += 1
    elif tot == M:
        cnt += 1; tot -= a[lt]; lt += 1
    else:
        tot -= a[lt]; lt += 1
```

---

### 6. 격자판 최대합
- **접근**: 행별 합, 열별 합, 두 대각선 합을 모두 구해 최댓값 출력
- **핵심 (최적화 ver)**: 대각선을 이중 반복문(O(N²)) 대신 단일 반복문(O(N))으로 처리
```python
for i in range(N):
    hap += gap[i][i]          # 주 대각선
for i in range(N):
    hap += gap[i][N-1-i]      # 반대 대각선
```

---

### 7. 사과나무 (다이아몬드)
- **접근**: 중앙에서 시작해 위쪽은 범위를 넓히고 아래쪽은 좁히는 방식으로 합산
- **핵심**: `s`, `e` 포인터로 각 행의 탐색 범위 동적 조절
```python
s = e = N // 2
for i in range(N):
    for j in range(s, e+1):
        res += a[i][j]
    if i < N // 2: s -= 1; e += 1
    else:          s += 1; e -= 1
```

---

### 8. 곳감 (모래시계)
- **접근**: 행 회전 후 모래시계 모양의 합 계산
- **핵심**: 리스트 왼쪽 회전 `append(pop(0))` / 오른쪽 회전 `insert(0, pop())`
```python
if t == 0:  # 왼쪽 회전
    a[h-1].append(a[h-1].pop(0))
else:        # 오른쪽 회전
    a[h-1].insert(0, a[h-1].pop())
```

---

### 9. 봉우리
- **접근**: 가장자리를 0으로 패딩한 뒤 상하좌우 인접 원소보다 큰 경우 카운트
- **핵심**: 방향벡터 `dx`, `dy` + `all()` 함수로 간결하게 표현
```python
dx = [-1, 0, 1, 0]
dy = [0, 1, 0, -1]
if all(a[i][j] > a[i+dx[k]][j+dy[k]] for k in range(4)):
    cnt += 1
```

---

### 10. 스도쿠 검사
- **접근**: 행/열/3×3 박스가 1~9를 중복 없이 포함하는지 검증
- **핵심**: 각 단위를 `set`으로 변환해 `{1,2,...,9}`와 비교

---

### 11. 격자판 회문수
- **접근**: 7×7 격자에서 가로/세로 방향으로 길이 5인 회문 구간의 개수 카운트
- **핵심**: 가로는 슬라이싱 `[i:i+5]`, 세로는 인덱스 직접 접근 후 `[::-1]` 비교

## 💡 핵심 개념 정리

| 개념 | 설명 |
|------|------|
| **투 포인터** | 두 인덱스를 움직여 O(N)에 구간합 탐색 |
| **방향벡터 (dx, dy)** | 상하좌우 이동을 배열로 표현, 코드 간결화 |
| **`all()` 함수** | iterable의 모든 조건이 참일 때 True 반환 |
| **리스트 회전** | `append(pop(0))` 왼쪽 / `insert(0, pop())` 오른쪽 |
| **0 패딩** | 경계 처리를 단순화하기 위해 가장자리에 0 추가 |
| **문자열 회문 판별** | `s == s[::-1]` 한 줄로 확인 |
| **ASCII 활용** | `ord()` 함수로 문자를 숫자 코드로 변환 |
