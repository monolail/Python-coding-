## 📂 섹션 2 - 코드 구현능력 기르기

> 기본적인 반복문, 조건문, 함수 설계 능력을 기르는 문제들로 구성되어 있습니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | K번째 약수 | 반복문, 약수 탐색 |
| 2 | K번째 수 | 리스트 슬라이싱, 정렬 |
| 3 | K번째 큰 수 | 3중 반복문, 집합(set) |
| 4 | 대표값 | 평균, 최솟값 탐색 |
| 5 | 정다면체 | 이중 반복문, 딕셔너리, 빈도수 계산 |
| 6 | 자릿수의 합 | 문자열 변환, 함수 정의 |
| 7 | 소수 (에라토스테네스의 체) | 소수 판별, 최적화 알고리즘 |
| 8 | 뒤집은 소수 | 문자열 뒤집기, 소수 판별 |
| 9 | 주사위 게임 | 조건 분기, 점수 계산 |
| 10 | 점수 계산 | 연속 정답 점수 누적 |

### 💡 주요 학습 내용

- **브루트포스 (완전탐색)**: 가능한 모든 경우를 탐색하는 접근법
- **에라토스테네스의 체**: 소수를 효율적으로 구하는 알고리즘
- **Set 자료구조**: 중복 제거 및 집합 연산 활용
- **함수 분리**: 가독성과 재사용성을 위한 함수 설계
- **딕셔너리 활용**: 빈도수 계산 및 카운팅

## 📂 섹션 3 - 탐색 & 시뮬레이션

> 2차원 배열 탐색, 문자열 처리, 투 포인터 등 핵심 탐색/시뮬레이션 기법을 익히는 문제들입니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | 회문 문자열 검사 | 문자열 뒤집기, 대소문자 처리 |
| 2 | 숫자만 추출 | 문자열 파싱, isnumeric / ASCII 활용 |
| 3 | 카드 역배치 | 리스트 인덱스 스왑, 구간 뒤집기 |
| 4 | 두 리스트 합치기 | 리스트 병합, 정렬 |
| 5 | 수들의 합 | 투 포인터(Two Pointer) |
| 6 | 격자판 최대합 | 2차원 배열, 행/열/대각선 합 |
| 7 | 사과나무 (다이아몬드) | 2차원 배열, 다이아몬드 패턴 탐색 |
| 8 | 곳감 (모래시계) | 리스트 회전, 모래시계 합 계산 |
| 9 | 봉우리 | 2차원 배열, 방향벡터, `all()` 함수 |
| 10 | 스도쿠 검사 | 행/열/3×3 박스 검증 |
| 11 | 격자판 회문수 | 슬라이싱, 가로/세로 회문 탐색 |

### 💡 주요 학습 내용

- **투 포인터**: 정렬된 배열에서 두 포인터로 구간합을 O(N)에 탐색
- **방향벡터 (dx, dy)**: 상하좌우 이동을 배열로 표현하는 기법
- **2차원 배열 탐색**: 행/열/대각선 합, 다이아몬드/모래시계 패턴
- **리스트 회전**: `append(pop(0))` vs `insert(0, pop())`
- **`all()` 함수**: 조건을 한 줄로 간결하게 검사
- **문자열 슬라이싱**: `[::-1]`로 뒤집기, `[i:i+5]`로 구간 추출

## 📂 섹션 4 - 정렬 & 이분탐색 / 그리디

> 정렬 알고리즘의 원리를 이해하고, 이분탐색으로 O(log N) 탐색을 구현합니다.  
> 그리디(탐욕) 알고리즘을 활용해 최적해를 빠르게 구하는 문제들을 다룹니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | 이분 검색 | 정렬, 이분탐색 |
| 2 | 랜선 자르기 | 파라메트릭 서치 (결정 알고리즘) |
| 3 | 뮤직 비디오 | 파라메트릭 서치 |
| 4 | 마구간 정하기 | 이분탐색, 그리디 |
| 5 | 회의실 배정 | 그리디, 정렬(기준 설정) |
| 6 | 씨름 선수 | 정렬, 최댓값 갱신 |
| 7 | 창고 정리 | 반복 정렬 시뮬레이션 |
| 8 | 침몰하는 타이타닉 | 그리디, 큐/투 포인터 |
| 9 | 증가 수열 | 그리디, 투 포인터 |
| 10 | 역수열 | 배열 인덱스 활용 시뮬레이션 |

### 💡 주요 학습 내용

- **이분탐색**: 정렬된 배열에서 `mid` 값을 기준으로 탐색 범위를 1/2씩 좁히는 탐색 (O(log N))
- **파라메트릭 서치(Parametric Search)**: 최적화 문제를 결정 문제(yes/no)로 바꾸어 이분탐색으로 최적해를 찾는 기법
- **그리디(Greedy)**: 각 단계에서 지금 당장 가장 좋은 선택을 하여 최적해에 도달하는 기법
- **다중 기준 정렬**: `lambda` 식을 활용해 우선순위에 따른 정렬 구현
- **투 포인터/양방향 접근**: 배열의 양쪽 끝에서 동시에 접근하여 조건 검사

## 🗂️ 섹션 5 - 자료구조 (스택, 큐, 해쉬, 힙)

> 알고리즘 구현에 필수적인 자료구조의 원리를 이해하고 활용합니다.  
> 스택(Stack)을 활용한 LIFO 구조와 문제 풀이 패턴을 주로 학습합니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | 가장 큰 수 | 스택, 그리디 |
| 2 | 쇠막대기 | 스택, 괄호 쌍 맞추기 |
| 3 | 후위표기식 만들기 | 스택, 연산자 우선순위 |
| 4 | 후위식 연산 | 스택 연산 |
| 5 | 공주 구하기 | 큐(Queue) 시뮬레이션 |
| 6 | 응급실 | 큐, 우선순위 시뮬레이션 |
| 7 | 교육과정 설계 | 큐 순서 검증 |
| 8 | 단어 찾기 | 해쉬, 딕셔너리 요소 제거 |
| 9 | Anagram | 해쉬, 딕셔너리 빈도수 비교 |
| 10 | 최소힙 | 우선순위 큐, `heapq` 모듈 |
| 11 | 최대힙 | 힙의 부호 반전 기법 |

### 💡 주요 학습 내용

- **스택 (Stack)**: LIFO (Last In First Out) 구조의 자료구조로 괄호 짝 맞추기, 과거 이력 관리에 유용
- **큐 (Queue)**: FIFO (First In First Out) 구조의 자료구조로 순서가 있는 대기열, 순환 시뮬레이션에 유용
- **해쉬 (Hash / Dictionary)**: Key-Value 구조로 빈도수 카운트 및 O(1) 시간 복잡도의 빠른 검색에 유용
- **힙 (Heap)**: 완전이진트리 기반 우선순위 큐로, 최솟값/최댓값을 O(log N)으로 관리 (`heapq` 모듈)
- **`pop()`과 `append()`**: 파이썬 리스트를 활용한 스택/큐 연산 (스택: `pop()`, 큐: `pop(0)`)
- **`dict.get(key, default)`**: 딕셔너리에서 안전하게 값을 가져오고 초기화하는 방법
