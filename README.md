## 📂 섹션 2 - 코드 구현능력 기르기

> 기본적인 반복문, 조건문, 함수 설계 능력을 기르는 문제들로 구성되어 있습니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | K번째 약수 | 반복문, 약수 탐색 |
| 2 | K번째 수 | 리스트 슬라이싱, 정렬 |
| 3 | K번째 큰 수 | 3중 반복문, 집합(set) |
| 4 | 대표값 | 평균, 최솟값 탐색 |
| 5 | 정다면체 | 이중 반복문, 딕셔너리, 빈도수 계산 |
| 6 | 자릿수의 합 | 문자열 변환, 함수 정의 |
| 7 | 소수 (에라토스테네스의 체) | 소수 판별, 최적화 알고리즘 |
| 8 | 뒤집은 소수 | 문자열 뒤집기, 소수 판별 |
| 9 | 주사위 게임 | 조건 분기, 점수 계산 |
| 10 | 점수 계산 | 연속 정답 점수 누적 |

### 💡 주요 학습 내용

- **브루트포스 (완전탐색)**: 가능한 모든 경우를 탐색하는 접근법
- **에라토스테네스의 체**: 소수를 효율적으로 구하는 알고리즘
- **Set 자료구조**: 중복 제거 및 집합 연산 활용
- **함수 분리**: 가독성과 재사용성을 위한 함수 설계
- **딕셔너리 활용**: 빈도수 계산 및 카운팅

## 📂 섹션 3 - 탐색 & 시뮬레이션

> 2차원 배열 탐색, 문자열 처리, 투 포인터 등 핵심 탐색/시뮬레이션 기법을 익히는 문제들입니다.

### 🔢 문제 목록

| # | 문제명 | 핵심 개념 |
|---|--------|-----------|
| 1 | 회문 문자열 검사 | 문자열 뒤집기, 대소문자 처리 |
| 2 | 숫자만 추출 | 문자열 파싱, isnumeric / ASCII 활용 |
| 3 | 카드 역배치 | 리스트 인덱스 스왑, 구간 뒤집기 |
| 4 | 두 리스트 합치기 | 리스트 병합, 정렬 |
| 5 | 수들의 합 | 투 포인터(Two Pointer) |
| 6 | 격자판 최대합 | 2차원 배열, 행/열/대각선 합 |
| 7 | 사과나무 (다이아몬드) | 2차원 배열, 다이아몬드 패턴 탐색 |
| 8 | 곳감 (모래시계) | 리스트 회전, 모래시계 합 계산 |
| 9 | 봉우리 | 2차원 배열, 방향벡터, `all()` 함수 |
| 10 | 스도쿠 검사 | 행/열/3×3 박스 검증 |
| 11 | 격자판 회문수 | 슬라이싱, 가로/세로 회문 탐색 |

### 💡 주요 학습 내용

- **투 포인터**: 정렬된 배열에서 두 포인터로 구간합을 O(N)에 탐색
- **방향벡터 (dx, dy)**: 상하좌우 이동을 배열로 표현하는 기법
- **2차원 배열 탐색**: 행/열/대각선 합, 다이아몬드/모래시계 패턴
- **리스트 회전**: `append(pop(0))` vs `insert(0, pop())`
- **`all()` 함수**: 조건을 한 줄로 간결하게 검사
- **문자열 슬라이싱**: `[::-1]`로 뒤집기, `[i:i+5]`로 구간 추출
