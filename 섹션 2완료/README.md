## 🔢 문제 목록 및 풀이 요약

### 1. K번째 약수
- **접근**: 1부터 N까지 순회하며 약수 개수를 세다가 K번째 약수를 출력
- **핵심**: `for-else` 구문 활용 (반복문이 정상 종료되면 -1 출력)
```python
for i in range(1, N+1):
    if N % i == 0:
        cnt += 1
    if K == cnt:
        print(i)
        break
else:
    print(-1)
```

---

### 2. K번째 수
- **접근**: 리스트 슬라이싱 후 정렬하여 K번째 원소 출력
- **핵심**: `a[s-1:e]` 슬라이싱 + `.sort()`

---

### 3. K번째 큰 수
- **접근**: 3중 반복문으로 세 수의 합을 모두 구한 뒤 `set`으로 중복 제거
- **핵심**: `set` 자료구조로 중복 없이 관리 후 내림차순 정렬

---

### 4. 대표값
- **접근**: 평균과 각 원소의 차이를 구해 가장 가까운 값의 인덱스 출력
- **핵심**: 동점일 때 더 큰 값 우선 선택하는 조건 처리

---

### 5. 정다면체
- **접근**: 두 주사위 합의 모든 경우를 구해 최빈값 출력
- **핵심**: 딕셔너리로 빈도수 카운팅 / 배열 카운팅(최적화 ver)
```python
# 최적화: 배열 카운팅
cnt = [0] * (N + M + 3)
for i in range(1, N+1):
    for j in range(1, M+1):
        cnt[i+j] += 1
```

---

### 6. 자릿수의 합
- **접근**: 각 숫자를 문자열로 변환하여 자릿수 합 계산 후 최댓값 탐색
- **핵심**: 함수 분리(`digit_sum`)로 가독성 향상

---

### 7. 소수 (에라토스테네스의 체)
- **접근**: 에라토스테네스의 체 알고리즘으로 1~N 사이 소수 개수 카운트
- **핵심**: O(N log log N) 시간복잡도의 효율적인 소수 판별법
```python
gap = [0] * (N + 1)
for i in range(2, N+1):
    if gap[i] == 0:
        cnt += 1
    for j in range(i, N+1, i):
        gap[j] += 1
```

---

### 8. 뒤집은 소수
- **접근**: 각 숫자를 뒤집은 뒤 소수인지 판별
- **핵심**: 문자열 슬라이싱 `[::-1]`으로 뒤집기 + 소수 판별 함수

---

### 9. 주사위 게임
- **접근**: 세 주사위 값의 조합 조건에 따라 점수 계산
- **핵심**: 조건 분기 (3개 같음 → 2개 같음 → 모두 다름)

---

### 10. 점수 계산
- **접근**: 연속 정답 시 누적 포인트 증가, 오답 시 리셋
- **핵심**: 연속성 카운터 변수 `p` 관리
```python
for i in a:
    if i == 1:
        sum += p
        p += 1
    else:
        p = 1
```
